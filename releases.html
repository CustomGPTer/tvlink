Release notes

What changed in each version of TVLink. The newest is at the top.

Version 1.2.1 26 November 2026Latest

  • More apps in Settings lists the developer's other free apps by group, each opening its website.
  • Check for updates in Settings opens the releases page in your browser. TVLink itself still never goes online.
  • New bottom bar. Docked to the bottom of the screen, with the selected page shown by a pill behind its icon.
  • Favourite and mode buttons now fit their names on one line, such as a favourite called Games console.
  • Activities with one step now say "1 step".
  • About shows "Developed by Jonathan Jackson ©".

Version 1.2.0 25 November 2026

  • Streaming buttons for 14 services, between Favourites and Extra controls, chosen and ordered for each TV.
  • On Samsung, LG, Sony, Philips and Fire TV, TVLink checks which apps the TV has and greys out the ones it does not.
  • Choose an installed app, enter your own app ID or mark a service unavailable for each TV.

Version 1.1.2 25 November 2026

  • Drawn icons for channel up and down, subtitles, info, the coloured keys, Exit and HDMI inputs, with larger captions that follow your font size.

Version 1.1.1 25 November 2026

  • Fixed Android TV and Google TV pairing failing with a secure-connection error. Pair once more after installing.

Version 1.1.0

  • Philips PIN pairing over a secure connection, and Panasonic encrypted pairing with HDMI input selection.
  • Pairing forms that match each TV's code format, and safer handling of failed pairings.

Version 1.0

  • First release. Wi-Fi control for Samsung, LG, Sony, Philips, Panasonic, Android TV and Google TV, and infrared on phones with an IR blaster.
  • Eight skins, four remote modes, favourites, activities, widgets, notification controls, a sleep timer, an app lock and encrypted backups.

Checking your download

The file for version 1.2.1 is called TVLink.apk. It is 1.9 MB (1,941,141 bytes). Its SHA-256 checksum is:

cfe3e97f21c9393331cceec9cc68302921e696394c5cf32b304bce2c37a024a0

On Windows, run certutil -hashfile TVLink.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
